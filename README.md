# RelayRunner Homebrew tap

```sh
brew install --cask relayrunner/tap/relayrunner
```

Installs RelayRunner for Mac, the menu bar app that takes GitHub Actions jobs on your Mac. It updates itself after that. The cask is bumped by `apps/mac/scripts/release.sh` in [relayrunner/relayrunner](https://github.com/relayrunner/relayrunner).
